      Como pegar o código do computador (Hardware ID)

      A chave de licença é amarrada ao computador do cliente. Primeiro o cliente te manda o ID do computador dele; você gera a chave para esse ID.

      1. No computador do cliente, abra o app e vá no menu Licença (em alguns aparece como Licença e Assinatura).
      2. Lá aparece “ID deste computador” com um botão Copiar e um QR Code.
      3. Jeito mais rápido: o cliente clica em Copiar (ou em Renovar licença, que já monta a mensagem) e te manda o ID pelo WhatsApp.
      4. Aqui no gerador, na aba Emitir, cole o ID no campo Hardware ID — ou toque em 📷 Ler QR da tela do cliente e aponte a câmera para o QR. O ID entra sozinho, já no produto certo.
      Importante — uma licença por computador
      Cada computador tem um ID fixo e recebe uma chave. Plano de 3 máquinas = 3 chaves, uma para o ID de cada computador.
      Cliente novo: instale e ative no notebook/computador que ele vai usar de verdade — o ID nasce ali. O ID é estável (vem do identificador do Windows e fica gravado), não muda com WiFi, Bluetooth nem pendrive espetado.
      Por que não usar uma foto antiga do ID

      No passado um app chegou a usar um ID que mudava com a rede/pendrive, e a licença parecia “sumir” (o cliente via o teste de novo). Isso foi corrigido — hoje o ID é fixo. Mesmo assim, sempre gere a chave para o ID que o cliente mostra agora na tela de Licença, nunca de uma foto ou print antigo: se não bater, a chave não ativa naquela máquina.
